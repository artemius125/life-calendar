# Календарь жизни

Визуальный календарь всей жизни в одном HTML-файле — без зависимостей, без сервера.

Каждая клетка — одна неделя. Прошедшие недели заполнены, текущая светится золотым, будущие обозначены контуром.

![screenshot](screenshot.png)

## Возможности

- Сетка 71 год × 52 недели с цветовым градиентом (синий → фиолетовый)
- Живой счётчик прожитого времени — дни, часы, минуты, секунды
- Статистика: дней / недель / месяцев / лет прожито
- Точный возраст, обратный отсчёт до дня рождения, дата конца жизни
- Прогресс-бар с процентом прожитой жизни
- Тултип с датами при наведении на любую клетку
- Подсветка всего года при наведении на строку
- Анимация появления при загрузке
- Автоскролл к текущей неделе
- Кнопка «● сейчас» для возврата к текущей позиции

## Использование

Открыть `life_calendar.html` в браузере. Файл не требует интернета.

Чтобы изменить дату рождения или продолжительность жизни — отредактировать две строки в начале скрипта:

```js
const BIRTH    = new Date(2001, 4, 12); // месяцы: 0=янв … 4=май … 11=дек
const LIFESPAN = 71;
```
